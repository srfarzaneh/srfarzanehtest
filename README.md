# راهنمای سایت

## ساختار فایل‌ها
| فایل | کاربرد |
|---|---|
| `index.html` | صفحه اصلی (هوم‌پیج) |
| `products.html` | صفحه کاتالوگ محصولات (جستجو + فیلتر) |
| `products-data.js` | **تنها فایلی که برای افزودن محصول یا تغییر شماره واتساپ ویرایش می‌کنی** |
| `main.js` | منطق نمایش، فیلتر و ساخت لینک واتساپ — معمولاً نیازی به ویرایش نیست |
| `style.css` | استایل‌ها |
| `fonts/` | فونت فارسی Vazirmatn (روی همین ریپازیتوری میزبانی می‌شود) |
| `images/` | اینجا رو خودت می‌سازی؛ عکس محصولات رو داخلش آپلود کن |

## افزودن محصول جدید
داخل `products-data.js`، یک بلوک مثل نمونه‌های موجود به آرایه `PRODUCTS` اضافه کن:

```js
{
  id: "product-slug",              // فقط حروف لاتین و خط تیره
  category: "دسته‌بندی محصول",
  name: "نام محصول",
  description: "توضیح کوتاه و عمومی محصول",
  models: ["BQ", "NQ", "HQ"],      // کدهای مدل/سایز
  image: "images/product-slug.jpg" // مسیر عکس (پایین‌تر توضیح داده شده)
},
```
همین الگو رو تا رسیدن به ۸۰ محصول تکرار کن. فیلترهای بالای صفحه محصولات خودکار از روی مقدار `category` تمام محصولات ساخته می‌شن — نیازی نیست جای دیگه‌ای هم چیزی اضافه کنی.

## عکس محصولات
هر کارت محصول به‌صورت پیش‌فرض دنبال فایلی می‌گرده که در `image` نوشتی (مثلاً `images/product-slug.jpg`). تا وقتی اون عکس رو آپلود نکردی، یک جای‌گزین ساده (آیکون + نوشته «تصویر محصول») به‌جاش نشون داده می‌شه — یعنی چیزی «خراب» به نظر نمی‌رسه. همین که عکس واقعی رو با همون مسیر/اسم داخل پوشه `images` آپلود کنی، بدون هیچ تغییری در کد، جای پلیس‌هولدر می‌شینه.

## تغییر شماره واتساپ و نام برند
بالای `products-data.js`، آبجکت `CONFIG` رو ویرایش کن:
```js
const CONFIG = {
  whatsappNumber: "98912XXXXXXX", // با کد کشور، بدون + و بدون فاصله
  companyName: "نام برند شما",
  tagline: "شعار یا توضیح کوتاه",
};
```
این مقدار در همه‌ی دکمه‌های واتساپ سایت (چه در هدر، چه زیر هر محصول) به‌صورت خودکار استفاده می‌شه.

## فونت
فونت فعلی، Vazirmatn (متن‌باز و رایگان) است و مستقیماً از همین ریپازیتوری بارگذاری می‌شه — بدون وابستگی به Google Fonts یا هر سرویس خارجی دیگه (برای پایداری بیشتر روی اینترنت داخل ایران). هروقت فایل‌های Kahroba رو آماده کردی، می‌تونیم به‌جای Vazirmatn جایگزینش کنیم.
